## ⚙️ Requirement

Sebutkan kebutuhan sistem/dependency sebelum instalasi:

- OS: `Ubuntu 22.04 / 24.04`
- Akses: `root / sudo`
- Dependency: `curl`, `git`, dll
- Versi minimum tools terkait (jika ada)

## 🚀 Instalasi

Langkah-langkah instalasi, tulis dalam bentuk perintah agar mudah di-copy:

```bash
sudo apt update
sudo apt install -y <package-name>
```
