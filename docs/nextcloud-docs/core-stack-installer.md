<h1 align="center">Core Installer NextCloud Extension</h1>

<p align="center">
Cara Passthrough atau Bypass Disk agar langsung size performa langsung masuk ke dalam VM nya
</p>

<p align="center">

![Platform](https://img.shields.io/badge/Platform-Proxmox-E56524?style=flat&logo=proxmox&logoColor=white) ![Service](https://img.shields.io/badge/Service-Nextcloud-0082C9?style=flat&logo=nextcloud&logoColor=white)

</p>

---
### Install NGINX
```bash
sudo apt update
sudo apt install nginx -y
```
---
### Install PHP + Extension
```bash
sudo apt install -y \
php-fpm php-cli php-common \
php-mysql php-gd php-curl php-xml \
php-zip php-mbstring php-intl \
php-bcmath php-gmp php-imagick \
php-bz2 php-apcu php-redis
```
---
### Install MariaDB or MySQL
```bash
sudo apt install mariadb-server mariadb-client -y
```
---
### Install Redis Server
```bash
sudo apt install redis-server -y
```
