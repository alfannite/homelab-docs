<h1 align="center">REDIS SERVER CLI COMMAND HELPER</h1>

<p align="center">
Helper command Redis Server Membantu kita untuk lihat log dan Trace Error yang ada
</p>

<p align="center">


![Redis](https://img.shields.io/badge/redis-%23DD0031.svg?style=for-the-badge&logo=redis&logoColor=white)

</p>

---
### Masuk Redis-CLI
```bash
redis-cli
```
### Test
```bash
ping
```
### Check Redis Dipakai
```bash
redis-cli INFO clients

redis-cli INFO memory
```
### Verify apakah Redis sudah di pakai
```bash
redis-cli MONITOR
```
